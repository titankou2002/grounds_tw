CH 01

專案概要

台灣主責（文件維護）▼
✔ 先做什麼
☐把整體藍圖（網站＋本文件）定案，作為台日共同版本
目的讓台灣端和日本總部從同一份文件出發，避免兩邊各自改版、訊息對不上
  1. 確認本文件的最終版本編號與發布位置（存放於檔案庫與網站文件區）
  2. 把 14 章逐一過一遍，每一章標註目前狀態：已定案／待日本確認／台灣自行推動
  3. 把「版本規則」寫進文件開頭：每次跟日本開會後同日更新，並註記改動摘要
  4. 存成一份固定網址的線上版本，讓日本總部永遠看得到最新的那一份
☐建立決策紀錄表
目的每筆關鍵決定都有「誰、何時、決定了什麼」，幾個月後不會各說各話
  1. 建一份共用工作表，欄位：日期／決定事項／參與者／決策內容／後續動作／誰負責／下次確認日
  2. 本週就回填目前已做成的決定（商標採日本母公司名義、送三類、標準程序送件等）
  3. 訂成固定習慣：每次跟日本對話後 24 小時內補上紀錄
  4. 每週五會議前，把「本週新增決定」列印出來當開會第一頁
▶ 開店要注意的事
  • 把所有執行時程集中在一份「開店倒數行事曆」：裝修、進貨、系統上線、招募、開幕每一項都有日期與負責人，避免各做各的
  • 文件只有一份總表、其餘全部連結引用，改版要在同一處改，避免出現兩份內容打架
  • 每週固定一個檢視時點（例如週五）確認哪些到期、哪些延誤，延誤就要立刻標註影響到哪一章
CH 02

品牌哲學

日本主責（品牌內容原始資料）台灣執行在地化▼
✔ 先做什麼
☐向日本索取品牌原始素材
目的品牌歷史、設計理念、型錄這類原始資料在日本人手上，不開口索取不會自己過來
  1. 列出需要的素材清單：官網與社群帳號、品牌歷史與理念文件、Mikio Sakabe設計概念、LEAP GRAVITY素材、型錄與公關資料
  2. 把清單整理成一頁「素材索取表」，逐項標明用途（店內陳列／教育訓練／社群文案）與使用期限
  3. 透過週五會議正式提出，並請日本指定一位素材窗口
  4. 索取到的素材統一存放，並註明授權範圍（能否商業使用、能否中文改製）
☐把素材翻譯與在地化，建立共用素材庫
目的日本原文直接拿來台灣消費者看不懂，需要翻成台灣人熟悉的語言
  1. 優先翻譯第一批：品牌故事、設計理念、主力鞋款介紹
  2. 建立「共用詞彙表」：把日文專有名詞統一翻譯成台灣說法（例如保留日文原名的、需要意譯的各列一行）
  3. 把檔案分類建檔：品牌故事／商品介紹／形象照／影片，供陳列、訓練、社群取用
  4. 在素材庫首頁放使用規範說明，避免有人誤用未授權素材
▶ 開店要注意的事
  • 品牌名稱與 Logo 的規範先寫死：中文怎麼標示（「GROUNDS／grounds」用哪一個）、字型、配色、Logo 版位，全店統一，亂了品牌感就跑掉
  • 素材授權範圍一定先問清楚並寫下來：能不能進店內放大輸出、能不能印在袋子／名片／社群，誰可以改製，使用期限到何時——這些不寫清楚，店開到一半才發現不能商用就麻煩
  • 翻譯用語一致性：建立共用詞彙表的原因就在這，同一個日文名詞店內招牌、IG、官網、客人話術四處不能講不同版本
  • 素材檔案規格統一收集：原始檔（AI/PDF/高解析圖）和輸出用檔分開放，避免店內輸出時找不到大圖
CH 03

商品哲學

日本核准商品線台灣提出市場建議▼
✔ 先做什麼
☐決定初期引進全系列還是部分系列
目的不先決定引進範圍，進貨、庫存、店面陳列空間全都無法往下走
  1. 盤點日本全系列清單，列成表格：系列名稱／定位／在台灣的預估接受度／價格帶
  2. 按「台灣市場契合度高→低」排序，圈出台灣側建議優先引進的系列
  3. 每組系列附一行推薦理由，做成「建議清單」，送日本裁示
  4. 日本回覆後回填決策紀錄表，並據此後續排進貨順序
☐取得各系列的產品知識教材
目的教育式試穿要能講出故事與材質，需要日本原本的產品知識當原料
  1. 向日本索取每個系列的：故事、材質、技術說明
  2. 整理成「商品知識卡」：一卡一款（故事／材質／技術／適合對象／話術提示）
  3. 標記優先順序：首批主打系列先做
  4. 成品當作教育訓練教材，同時放進共用素材庫供社群取用
▶ 開店要注意的事
  • 台灣的尺碼分布和日本不一定一樣：女鞋主流集中在哪些日碼／歐碼要比對台灣市場實際銷售數據，首批不要平均鋪碼，抓主要的 3-4 個尺碼下重
  • 鞋底（泡棉／厚底）在台灣高溫多雨環境的磨耗與發霉風險要先問清保養方式，並在話術／售後說明裡寫清楚
  • 庫存週轉：鞋類過季幾乎無法原價賣，引進的量要保守、多批少進，寧可缺貨也不要囤死貨
  • 台灣沒有明顯的冬季長靴需求，季節分界跟日本不同，進貨月份要對照台灣的換季節奏而不是日本的
CH 04

台灣市場分析

台灣主責▼
✔ 先做什麼
☐完成台灣市場分析
目的定位、消費力、日本品牌接受度、競爭態勢這塊不需等日本，台灣自己就能做完
  1. 先寫市場定位與消費能力：蒐集台灣鞋類市場規模、機能性鞋款／設計師鞋款在台的價格帶與銷售結構，整理成一段結論
  2. 分析台灣消費者對日本設計師品牌的接受度：用捷運站點人流、網路討論聲量、競品定價三個面向交叉看
  3. 盤點直接競爭者（含與 GROUNDS 定位最接近的 GROUND FIVE）：比較價格帶、通路型態、社群經營方式
  4. 收尾成優劣勢分析（優勢／劣勢／機會／威脅），完成後送日本備查，並把關鍵數據回填到決策紀錄表
☐產出「品牌教育」計畫初稿
目的最大挑戰不是價錢／商圈／競爭者，而是消費者不知道 GROUNDS 是什麼——要先讓大家認識品牌
  1. 定溝通主軸：日本設計師品牌、獨特厚底、教育式試穿（先把一句話講清楚）
  2. 規劃內容管道與各自任務：官網（品牌故事落點）、IG（每日視覺）、LINE（會員通知）、接觸美妝／鞋類 KOL（發文與試穿開箱）、門市體驗（現場教育）
  3. 排出第一季的內容／活動節奏草案：一星期一篇主內容、每月一篇系列深度文、每季一支形象影片
  4. 每項內容定出「衡量指標」：貼文觀看數、互動數、導至官網人數，作為第一季檢討依據
☐訂出第一年關鍵指標草案
目的第一年不能只看營收，品牌曝光與顧客理解更重要
  1. 定義五個面向：品牌曝光、會員數、社群互動、品牌理解度、回購率
  2. 每個面向寫出可衡量的目標與量測方式（例如品牌理解度＝試穿後填問卷的正確回答率）
  3. 先訂「目標值」（營運第十二個月的月數字），第二季開始逐月檢視
  4. 與日本對齊後回填決策紀錄表
▶ 開店要注意的事
  • 市場數據要標註來源與年份，引用舊資料會讓整個分析失真；至少引用近 1-2 年內可查證的來源
  • 人流數據要分平日／假日、雨天／晴天看，只看假日高峰會高估銷售
  • 消費力評估不要只按行政區的「平均收入」，要對應到實際會走進店裡的那群人（年齡、消費習慣、是否會買設計師品牌）
  • GROUND FIVE 是近似的直接競品，除了價格帶也要比它怎麼鋪通路、怎麼做社群、評價如何，那是台灣市場最真實的參考
  • 商圈的四個數字都要實際拿到再下結論：租金、坪數、人流、周邊競品，缺一個就別拍板

CH 05

門市策略

日本決定定位台灣執行選址與裝修▼
✔ 先做什麼
☐盤點可能店址，做出 2-3 個候選方案
目的先有具體候選清單，日本才能從中選，而不是空談定位
  1. 列出候選區域（優先考慮中山北路二段36巷現址、附近商圈）
  2. 每個候選做比較表：租金、坪數、人流、曝光、裝修難度，各標一顆星到三顆星
  3. 每處候選拍現場照片＋畫粗略動線圖（入口在哪、主力陳列牆在哪）
  4. 產出一頁比較表，作為週五會議討論的基礎
☐把店鋪概念寫成具體構想書
目的讓日本看到台灣對店面想像的具體輪廓，加速拍板第一家店定位
  1. 寫一版店鋪概念：品牌調性（想傳達的氛圍）、空間感（大小、挑高、光線）、顧客進店後的體驗順序
  2. 勾勒視覺陳列重點：主力鞋牆怎麼排、教育式試穿區放哪、走道與動線怎麼留
  3. 標出「品牌旗艦店」與「市場驗證店」兩種設定的差異：前者重品牌形象（地點更核心、空間更大、裝修預算高），後者重力省成本快速驗證銷量
  4. 附 2-3 張參考圖（日本店鋪或類似店鋪）讓日本直覺了解台灣的想法
☐做一份店鋪裝修與設備的粗估預算表
目的定位一確定就能馬上動工，不用重新估，替日本省一輪來回
  1. 列出項目：木作／陳列架、地板牆面、燈光、試穿椅與鏡、結帳櫃台、招牌
  2. 先用「每坪裝修單價 × 坪數」估出總價區間
  3. 標註變數：坪數越大、挑高越高，費用越高；要不要改水電消防也寫清
  4. 兩種設定各出一版數字（旗艦店一版、驗證店一版）
▶ 開店要注意的事
  • 租約細節：押金幾倍、租期長短、有無漲租條款與幅度、能否轉租／變更承租人、裝修期租金怎麼算、仲介費誰出——這些在簽約前逐條寫進合約
  • 消防與安檢：開店前一定要通過消防設備檢查，沒通過不能營業；幾坪以上要辦理「建築物使用執照變更」？店面有無既有消防設備（滅火器、緊急照明、避難指示）？電容量夠不夠（鞋店燈多、冷氣＋刷卡機＋收銀）？
  • 水電：確認有獨立電錶、水電管線位置與容量，裝修後才發現跳電／拉線不足是常見大雷
  • 動線：店面入門→鞋牆→試穿區→結帳櫃台的流線先在平面圖上畫順，試穿區要有椅子和鏡子，別讓客人站著脫鞋
  • 庫存空間：後場或倉儲夠不夠放整季安全庫存，鞋盒多大、一季幾百雙要塞哪，別讓賣場堆紙箱
  • 招牌與廣告物：台北市對招牌、廣告物有申請規定，先確認店面外露招牌要不要申請許可，亂掛會被罰
  • 天氣：台灣夏天高溫多雨，騎樓或入口的防滑、冷氣夠不夠、下雨天鞋盒會不會受潮都要想
CH 06

台灣營運架構

雙方共同確認，之後台灣依此執行▼
✔ 先做什麼
☐把權責分工做成正式文件
目的誰決定什麼，白紙黑字定下來，避免日後灰色地帶
  1. 把日本保留的（品牌方向／年度預算／重大投資／品牌合作／第二店／重大設計／重大採購）與台灣負責的（門市／人事／排班／行政／日常營運／庫存／會員／活動／預算內執行）整理成左右對照表，並附「誰拍板、誰執行、誰知會」三欄
  2. 加上金額授權表：50 萬以下台灣核准、50 萬以上日本核准，並把「下列事項即使金額低也要日本核准」的清單列出來
  3. 定義例外處理：碰到表上沒寫到的事，先問哪一方、多久內回覆
  4. 正式送日本簽署確認，回填決策紀錄表
☐畫出台灣端組織圖草案
目的先定職位與權責架構，之後找人不慌
  1. 定職位：店長、正職、兼職、行銷／營運支援
  2. 標出每個職位的負責範圍與對應的權責分工權限
  3. 標出入職順序假設：第一家店開幕前先到位的職位、開幕後才補的職位
  4. 註明「先抓職位，人之後再補」
▶ 開店要注意的事
  • 勞基法令：排班、加班、特休、勞健保、勞退都要按台灣規定走，門市雙週工時（一例一休）在排班表上就要對好，被抓到罰鍰以外人事成本會被逼高
  • 門市 SOP：開店／閉店檢查清單、交接（現金、庫存、客人資訊）、異常回報流程，一張白紙黑字寫下來，不然每個人做法都不同
  • 現金與金流：收銀、刷卡、電子支付的每日對帳流程，現金短少誰負責、多久結一次，這是門市最容易出問題的地方之一
  • 盤點制度：多久盤一次、盤差怎麼處理，庫存數字不準，補貨和管銷全部失真
  • 保險：公共意外責任險、火險、竊盜險在開店前投保，發生事情才不會獨自吞
  • 後勤支援：店長之外誰負責叫修、補貨、帳務，有事時要有明確的聯絡網而不是只靠一個人

  3. 排定下次檢討時間（例如第一年財報出爐時）
▶ 開店要注意的事
  • 願景是要拿來做決定用的，不是掛在牆上的口號：寫完後，對應到「這一年要先做到哪幾件事」要有具體對應
  • 第一年的檢討點先排好（例如：開幕後 3 個月、半年、一年各看一次），時間到了就對照實際數據回顧，不要等「有空」才看
  • 把願景翻成店員聽得懂的方向（品牌精神一句話），不然教育訓練和日常服務會跟願景脫節

進口路線比較：日本 vs 印尼直接進口（2026-09-08 新增）

背景：grounds 鞋在印尼／中國的工廠生產（已確認，非日本製造）。因此比較「從日本進口」vs「從印尼直送」。

  • 台灣與印尼沒有自由貿易協定（台灣非 ASEAN 成員，所以 ATIGA／Form E 免關稅不適用於印尼→台灣）
  • 鞋類（海關稅則第64章）進口關稅約 6~10%（依材質），再加 5% 營業稅
  • 從日本轉口 → 原產地仍為印尼（不可偽報成日本製，違反《海關緝私條例》）
  • 結論：關稅面日本 vs 印尼幾乎無差別（都是 6~10% + 5%）；真正差別在交期、庫存、控制權
比較項目從日本進口（經 FOOLS 日本倉）從印尼直送（工廠直出）
關稅＋營業稅6~10% + 5%（原產地=印尼）6~10% + 5%（同）
交期（海運）日本→台灣 約 2~4 天印尼→台灣 約 7~14 天
交期（空運）日本→台灣 1~2 天印尼→台灣 3~7 天
最小訂購量 (MOQ)低，可少量多次補貨高，工廠有最低起訂
前置期（下單到到貨）短（FOOLS 有庫存可立即出）長（配合工廠排產，數週~數月）
庫存風險低（日方扛庫存）高（一次進大量壓資金）
換季/滯銷彈性好（可小量試）差（量大難退）
價格較貴（日本端加拉利潤/物流費）較便宜（省中間層）
品質/標籤控管由日本統一整合台灣端要自己盯中文標、BSMI
付款/匯率付日幣（與日方月結）付美金/印尼盾（風險自負）
供應鏈控制權完全交給日本台灣介入了訂貨決策
  1. 1. 開店第一階段（第一、二階段為主）→ 全走日本進口：交期短、小量多補、日方扛庫存、換季彈性大，最適合新品牌試水溫
  2. 2. 銷量穩定後（6~12 個月後）→ 用銷量數據與日本談部分熱銷款印尼直送：壓低成本，需有明確訂單量才划算（MOQ 效益）
  3. 3. 交易條件建議：初期談「寄售（Consignment）」或「買斷但小量高頻」，打通庫存與現金流，別一次押大量

會議重點：直接問日本——FOOLS 目前是「日本倉庫庫存出貨」還是「印尼/中國工廠指定品項出貨」？這決定台灣端庫存天數設定。

電商三階段策略（2026-09-08 新增）

核心原則：grounds 是設計師品牌，電商必須「品牌型」而非「折扣型」。第一年避開蝦皮/MOMO（量販平台、折扣文化，會吃掉品牌定位與門市價差）。

  • 日本有官方線上商店（grounds-fw.jp）
  • 台灣無本地電商，消費者透過選品店或日本官網購買
階段做法理由
初期（開店前~半年）走日本官網國際配送（DTC）或直營店，不開台灣電商避免折扣文化，保品牌；門市建立認知
中期（半年~一年）開台灣自有官網（品牌型電商）門市品牌基礎後，電商承接會員/回購；風格可控
後期視需要評估百貨/其他平台等品牌立足後再看，不為早期折扣犧牲形象
  • 台灣電商自行開官網，還是日本官網國際配送直送台灣？
  • 日本官網直送 → 初期零庫存，但個資跨境（台灣個資法）+ 電子發票、退換貨責任複雜
  • 台灣官網 → 綁電子發票、本地物流、需庫存
  • [ ] 電商貨從台灣庫存出，還是日本直寄？定價與庫存邊界怎麼切？
  • [ ] 平台策略：是否認同「初期不上蝦皮/MOMO」？

開店前置合規 Checklist（2026-09-08 新增）

開店落地有硬性時效、會影響營業時程的法規與行政面，逐一勾選。★ = 有硬性時效或會延誤營業，一定要提前。

  • ★ 子公司設立（名稱預查→投審會→籌備戶→匯資→投資審定→公司登記）
  • ★ 商業登記＋稅籍登記（開業前完成，未登記不得營業）
  • 關務登錄：取得進口人身分（報關用，決定關稅/營業稅繳納主體）
  • 印鑑登記、大小章
  • ★ 開設公司帳戶（外資：一般帳戶＋OBU／日圓、美金帳戶評估）
  • ★ 刷卡收單（零售銷售系統綁定金流，需提早申辦審核）
  • 第三方金流／電子支付評估（LINE Pay、街口等台灣常用）
  • 外幣匯款與匯率避險安排（尤其日本/印尼進貨付款）
  • ★ 委任記帳士／會計師（記帳、申報）
  • ★ 電子發票申請（加值型營業稅，每二個月申報一次）
  • 營業稅稅籍、統一發票購票證
  • 營所稅：暫繳、結算申報、未分配盈餘
  • 扣繳申報：員工薪資、房租扣繳 10%、給付外國人（日本）扣繳
  • 資本額查核簽證
  • ★ 室內裝修許可申請（動工前，需送審）
  • ★ 建築物使用執照／用途變更（土屋鞄現址含藝文空間，複合使用需確認）
  • ★ 消防會勘（消防檢查通過才能營業）
  • ★ 公共安全檢查（公安申報）（零售店面定期申報）
  • 電器檢查、逃生標示、滅火器配置
  • ★ 招牌廣告物管理（北市需申請、部分需雜項執照）
  • 樓地板/逃生動線符合零售規定
  • ★ 公共意外責任險（營業場所，多數縣市強制 + 消防審查會看）
  • 貨物/水險（進口途中）、火險（店面設備）
  • 員工團險（雇主責任、意外）
  • ★ 勞健保、勞退、職災保險、就業保險投保申報
  • 勞動契約書（僱用前簽署）
  • 工作規則（受僱勞工達 30 人以上需報備）
  • 排班/加班費/特休/工時上限（零售業排班法規）
  • 給付薪資依勞基法（薪資扣繳、加班費）
  • 員工個資蒐集同意
  • 會員資料（個資法）、監視器設置、員工資料保管
  • 跨境傳輸（若會員資料回傳日本，需個資法同意＋可能的跨境傳輸機制）
  • ★ 台灣商標（第25+35+18類）送件——優先於開店
  • 侵害風險盤點（品牌視覺、陳列、販售物是否用到他人權利）
  • 銷售／庫存／會員系統（含電子發票串接、刷卡收單）
  • 進口合規：中文標示、BSMI（見進口章節）
  • 庫存、物流倉儲、警報/保全
