CH 01

專案概要

台灣主責P1｜行事曆是排程樞紐，本週就要起頭，但不卡開店本身▼
✔ 先做什麼
☐把 14 章的執行項目排進一份「開店倒數行事曆」
目的裝修、進貨、系統、招募、開幕每件事都有日期和負責人，才看得出輕重、不會各做各的
  1. 把 14 章所有「先做什麼」動作按依賴關係排序，寫成第一版行事曆（月份＋里程碑）
  2. 標出會卡住別的的事（商標送件、公司成立、消防）優先往前排
  3. 每項標負責人（台灣端此刻就能指定到人）
  4. 每週五檢視一次：哪些到期、哪些延誤，延誤就標註影響到哪一章
▶ 開店要注意的事
  • 不排行事曆 → 各做各的、到期沒人知道，延誤也不對外警覺，開幕從這裡開始失控
  • 每章只有一份正本，其他地方一律用連結引用，改版在同一處改，避免出現兩份內容打架
  • 每週五用行事曆當檢視點：哪些到期、哪些延誤，延誤立刻標註影響到哪一章
CH 02

品牌哲學

日本主責（品牌內容原始資料）台灣執行在地化P1｜素材與翻譯要提早動手，開幕前內容才齊得出▼
✔ 先做什麼
☐向日本索取品牌原始素材
目的品牌歷史、設計理念、型錄這類原始資料在日本人手上，不開口索取不會自己過來
  1. 列出需要的素材清單：官網與社群帳號、品牌歷史與理念文件、Mikio Sakabe設計概念、LEAP GRAVITY素材、型錄與公關資料
  2. 把清單整理成一頁「素材索取表」，逐項標明用途（店內陳列／教育訓練／社群文案）與使用期限
  3. 透過週五會議正式提出，並請日本指定一位素材窗口
  4. 索取到的素材統一存放，並註明授權範圍（能否商業使用、能否中文改製）
☐把素材翻譯與在地化，建立共用素材庫
目的日本原文直接拿來台灣消費者看不懂，需要翻成台灣人熟悉的語言
  1. 優先翻譯第一批：品牌故事、設計理念、主力鞋款介紹
  2. 建立「共用詞彙表」：把日文專有名詞統一翻譯成台灣說法（例如保留日文原名的、需要意譯的各列一行）
  3. 把檔案分類建檔：品牌故事／商品介紹／形象照／影片，供陳列、訓練、社群取用
  4. 在素材庫首頁放使用規範說明，避免有人誤用未授權素材
▶ 開店要注意的事
  • 品牌不統一 → 店裡和 IG 講兩個版本，消費者對「grounds 是什麼」更困惑，教育式試穿的賣點直接破功
  • 素材授權沒確認就印刷上架 → 店開到一半被通知不能商用，看板、袋子、社群全部重來
  • 翻譯用語一致性：建立共用詞彙表的原因就在這，同一個日文名詞店內招牌、IG、官網、客人話術四處不能講不同版本
  • 素材檔案規格統一收集：原始檔（AI/PDF/高解析圖）和輸出用檔分開放，避免店內輸出時找不到大圖
CH 03

商品哲學

日本核准商品線台灣提出市場建議P1｜引進範圍不定，進貨就卡在起點，但可先排市場建議▼
✔ 先做什麼
☐決定初期引進全系列還是部分系列
目的不先決定引進範圍，進貨、庫存、店面陳列空間全都無法往下走
  1. 盤點日本全系列清單，列成表格：系列名稱／定位／在台灣的預估接受度／價格帶
  2. 按「台灣市場契合度高→低」排序，圈出台灣側建議優先引進的系列
  3. 每組系列附一行推薦理由，做成「建議清單」，送日本裁示
  4. 日本回覆後據此排進貨順序
☐取得各系列的產品知識教材
目的教育式試穿要能講出故事與材質，需要日本原本的產品知識當原料
  1. 向日本索取每個系列的：故事、材質、技術說明
  2. 整理成「商品知識卡」：一卡一款（故事／材質／技術／適合對象／話術提示）
  3. 標記優先順序：首批主打系列先做
  4. 成品當作教育訓練教材，同時放進共用素材庫供社群取用
▶ 開店要注意的事
  • 商品結構不先定 → 進了賣不動的貨，整批卡庫存、季末只能打折，毛利直接被吃掉
  • 尺碼分布抓錯 → 主力尺寸缺貨、冷門尺寸滯銷，來客試穿沒碼就走人
  • 鞋底（泡棉／厚底）在台灣高溫多雨環境的磨耗與發霉風險要先問清保養方式，並在話術／售後說明裡寫清楚
  • 庫存週轉：鞋類過季幾乎無法原價賣，引進的量要保守、多批少進，寧可缺貨也不要囤死貨
  • 台灣沒有明顯的冬季長靴需求，季節分界跟日本不同，進貨月份要對照台灣的換季節奏而不是日本的
CH 04

台灣市場分析

台灣主責P1｜定位靠數據，但現在就能用「本案待確認」往日本送，不必等分析完整▼
✔ 先做什麼
☐完成台灣市場分析
目的定位、消費力、日本品牌接受度、競爭態勢這塊不需等日本，台灣自己就能做完
  1. 先寫市場定位與消費能力：蒐集台灣鞋類市場規模、機能性鞋款／設計師鞋款在台的價格帶與銷售結構，整理成一段結論
  2. 分析台灣消費者對日本設計師品牌的接受度：用捷運站點人流、網路討論聲量、競品定價三個面向交叉看
  3. 盤點直接競爭者（含與 GROUNDS 定位最接近的 GROUND FIVE）：比較價格帶、通路型態、社群經營方式
  4. 收尾成優劣勢分析（優勢／劣勢／機會／威脅），完成後送日本備查
☐產出「品牌教育」計畫初稿
目的最大挑戰不是價錢／商圈／競爭者，而是消費者不知道 GROUNDS 是什麼——要先讓大家認識品牌
  1. 定溝通主軸：日本設計師品牌、獨特厚底、教育式試穿（先把一句話講清楚）
  2. 規劃內容管道與各自任務：官網（品牌故事落點）、IG（每日視覺）、LINE（會員通知）、接觸美妝／鞋類 KOL（意見領袖，社群上有影響力的人，發文與試穿開箱）、門市體驗（現場教育）
  3. 排出第一季的內容／活動節奏草案：一星期一篇主內容、每月一篇系列深度文、每季一支形象影片
  4. 每項內容定出「衡量指標」：貼文觀看數、互動數、導至官網人數，作為第一季檢討依據
☐訂出第一年關鍵指標草案
目的第一年不能只看營收，品牌曝光與顧客理解更重要
  1. 定義五個面向：品牌曝光、會員數、社群互動、品牌理解度、回購率
  2. 每個面向寫出可衡量的目標與量測方式（例如品牌理解度＝試穿後填問卷的正確回答率）
  3. 先訂「目標值」（營運第十二個月的月數字），第二季開始逐月檢視
  4. 與日本對齊後再更新目標值
▶ 開店要注意的事
  • 市場分析只用感覺、不拿數據 → 定位講錯、首批貨進錯，後面第五章到第十二章全部跟著錯
  • 數據不標年份來源 → 引用舊資料會讓整個分析失真，至少用近 1-2 年內可查證的來源
  • 人流數據要分平日／假日、雨天／晴天看，只看假日高峰會高估銷售
  • 消費力評估不要只按行政區的「平均收入」，要對應到實際會走進店裡的那群人（年齡、消費習慣、是否會買設計師品牌）
  • GROUND FIVE 是近似的直接競品，除了價格帶也要比它怎麼鋪通路、怎麼做社群、評價如何，那是台灣市場最真實的參考
  • 商圈的四個數字都要實際拿到再下結論：租金、坪數、人流、周邊競品，缺一個就別拍板

CH 05

門市策略

日本決定定位台灣執行選址與裝修P0｜消防沒過不能營業；選址不定，後面的裝修、預算全部懸空▼
✔ 先做什麼
☐盤點可能店址，做出 2-3 個候選方案
目的先有具體候選清單，日本才能從中選，而不是空談定位
  1. 列出候選區域（優先考慮中山北路二段36巷現址、附近商圈）
  2. 每個候選做比較表：租金、坪數、人流、曝光、裝修難度，各標一顆星到三顆星
  3. 每處候選拍現場照片＋畫粗略動線圖（入口在哪、主力陳列牆在哪）
  4. 產出一頁比較表，作為週五會議討論的基礎
☐把店鋪概念寫成具體構想書
目的讓日本看到台灣對店面想像的具體輪廓，加速拍板第一家店定位
  1. 寫一版店鋪概念：品牌調性（想傳達的氛圍）、空間感（大小、挑高、光線）、顧客進店後的體驗順序
  2. 勾勒視覺陳列重點：主力鞋牆怎麼排、教育式試穿區放哪、走道與動線怎麼留
  3. 標出「品牌旗艦店」與「市場驗證店」兩種設定的差異：前者重品牌形象（地點更核心、空間更大、裝修預算高），後者重力省成本快速驗證銷量
  4. 附 2-3 張參考圖（日本店鋪或類似店鋪）讓日本直覺了解台灣的想法
☐做一份店鋪裝修與設備的粗估預算表
目的定位一確定就能馬上動工，不用重新估，替日本省一輪來回
  1. 列出項目：木作／陳列架、地板牆面、燈光、試穿椅與鏡、結帳櫃台、招牌
  2. 先用「每坪裝修單價 × 坪數」估出總價區間
  3. 標註變數：坪數越大、挑高越高，費用越高；要不要改水電消防也寫清
  4. 兩種設定各出一版數字（旗艦店一版、驗證店一版）
▶ 開店要注意的事
  • 消防沒過 → 不能營業，開幕日直接跳票，最嚴重的一項
  • 租約沒逐條看清 → 漲租、不能轉租、裝修期照收全租，簽下去就被綁死
  • 消防與安檢：開店前一定要通過消防設備檢查，沒通過不能營業；幾坪以上要辦理「建築物使用執照變更」？店面有無既有消防設備（滅火器、緊急照明、避難指示）？電容量夠不夠（鞋店燈多、冷氣＋刷卡機＋收銀）？
  • 水電：確認有獨立電錶、水電管線位置與容量，裝修後才發現跳電／拉線不足是常見大雷
  • 動線：店面入門→鞋牆→試穿區→結帳櫃台的流線先在平面圖上畫順，試穿區要有椅子和鏡子，別讓客人站著脫鞋
  • 庫存空間：後場或倉儲夠不夠放整季安全庫存，鞋盒多大、一季幾百雙要塞哪，別讓賣場堆紙箱
  • 招牌與廣告物：台北市對招牌、廣告物有申請規定，先確認店面外露招牌要不要申請許可，亂掛會被罰
  • 天氣：台灣夏天高溫多雨，騎樓或入口的防滑、冷氣夠不夠、下雨天鞋盒會不會受潮都要想
CH 06

台灣營運架構

雙方共同確認，之後台灣依此執行P1｜權責不清會讓後續每個決定卡住，但還不卡開幕▼
✔ 先做什麼
☐把權責分工做成正式文件
目的誰決定什麼，白紙黑字定下來，避免日後灰色地帶
  1. 把日本保留的（品牌方向／年度預算／重大投資／品牌合作／第二店／重大設計／重大採購）與台灣負責的（門市／人事／排班／行政／日常營運／庫存／會員／活動／預算內執行）整理成左右對照表，並附「誰拍板、誰執行、誰知會」三欄
  2. 加上金額授權表：50 萬以下台灣核准、50 萬以上日本核准，並把「下列事項即使金額低也要日本核准」的清單列出來
  3. 定義例外處理：碰到表上沒寫到的事，先問哪一方、多久內回覆
  4. 正式送日本簽署確認
☐畫出台灣端組織圖草案
目的先定職位與權責架構，之後找人不慌
  1. 定職位：店長、正職、兼職、行銷／營運支援
  2. 標出每個職位的負責範圍與對應的權責分工權限
  3. 標出入職順序假設：第一家店開幕前先到位的職位、開幕後才補的職位
  4. 註明「先抓職位，人之後再補」
▶ 開店要注意的事
  • 權責沒先簽好 → 店開起來，5 成的決定會卡在半空中沒人拍板，日本也怕你一意孤行
  • 勞基法令：排班、加班、特休、勞健保、勞退都要按台灣規定走，門市雙週工時（一例一休）在排班表上就要對好，被抓到罰鍰以外人事成本會被逼高
  • 門市 SOP（標準作業流程，把做法寫成固定步驟的文件）：開店／閉店檢查清單、交接（現金、庫存、客人資訊）、異常回報流程，一張白紙黑字寫下來，不然每個人做法都不同
  • 現金與金流：收銀、刷卡、電子支付的每日對帳流程，現金短少誰負責、多久結一次，這是門市最容易出問題的地方之一
  • 盤點制度：多久盤一次、盤差怎麼處理，庫存數字不準，補貨和管銷全部失真
  • 保險：公共意外責任險、火險、竊盜險在開店前投保，發生事情才不會獨自吞
  • 後勤支援：店長之外誰負責叫修、補貨、帳務，有事時要有明確的聯絡網而不是只靠一個人
CH 07

公司成立

日本決策台灣執行設立流程P0｜公司沒成立，簽約、進貨、匯錢全部無法進行；商標先申請主義，愈快愈好▼
✔ 先做什麼
☐把「100%日本持股台灣子公司」建議整理成給日本拍的方案
目的日本看到清楚的建議＋理由，才好下決策，避免回覆「再看看」
  1. 整理子公司 vs 分公司比較表：品牌控制（子公司可留日本母公司名義）、治理、展店彈性、未來發展——每項寫一行利弊
  2. 寫出台灣建議用子公司的一頁理由，並預先補上日本可能問的三個反問（資本額多少、盈餘怎麼匯回、稅務怎麼處理）
  3. 列出子公司設立的時程預估（名稱預查→備文件→送件→登記約需幾週），讓日本知道拖一天就晚一天開店
  4. 排進週五會議正式請日本拍板
☐先聯繫會計師／律師事務所詢價
目的設立流程、時間、成本這類資訊現在就能問，不用等日本選子公司或分公司（兩種都需要類似資訊）
  1. 找 2-3 家會計師／律師事務所，準備同一份問題清單當面問取得報價
  2. 問清楚：外資來台設立流程、所需時間、費用明細、後續每年記帳費用
  3. 每家問完當天補一行重點摘要，整理成比較表
  4. 會議附給日本參考，並標出台灣側建議的選擇
▶ 開店要注意的事
  • ★ 台灣商標未註冊（2026-09-08確認）→ 任何人現在就能搶先註冊，搶走品牌名，等於替別人開店；台灣採先申請主義（註冊權先送先贏，不看誰先用），務必在開店前送件（品牌核心 3 件：GROUNDS／LEAP GRAVITY／圖片LOGO，至少各送第25＋35類），送件愈慢風險愈高。完整標的清單與費用見「商標佈局調查結果」章節
  • 公司名稱：先用經濟部商工登記資料查詢，名稱預查避開與既有公司近似（含 GROUND FIVE），名稱或地址跟實際營業不符後續帳務、報稅都會卡
  • 銀行開戶：公司帳戶、刷卡收單帳戶要提早申辦，銀行審核需要時間，別等開幕前一週才辦
  • 平台登記：營業登記、稅籍登記（向國稅局申請營業稅籍，等同稅務上的營業身份）、統一發票購票證在開業前完成，未登記不得營業、也無法開電子發票（發票以電子檔上傳國稅局的省紙化發票，台灣法規強制）
  • 外資金流：外資股本匯入、結匯都有申報程序，資金不到位會延後一堆工作，先排資金時程表
CH 08

進口與物流

日本決定出貨模式台灣執行在地報關與倉儲P1｜進貨前置期最長，越晚談越容易斷貨，但可先用詢價起頭▼
✔ 先做什麼
☐研究鞋類進口的稅則號列、稅率與報關流程
目的進口成本算得出來，定價與庫存才有依據
  1. 透過海關「稅則稅率查詢系統」查鞋類（海關稅則第64章）的稅則號列與關稅稅率（約6~10%）
  2. 把「船運到港→報關→放行→入倉」的流程與所需文件（商業發票、裝箱單、提單、報關委任書）列成檢查表
  3. 記錄台灣零售標示法規：中文標示、鞋類尺碼標示規定，先確認第一批貨要貼什麼
  4. 就第一批進貨試算一次完整的進口成本，含運費分攤、關稅、營業稅、報關手續費
☐詢價 2-3 家進口物流／報關代理商
目的抓出大概的物流成本結構，避免事後暴雷
  1. 找出 2-3 家台灣進口物流／報關代理
  2. 各拿一份報價（海運、空運、報關費、倉儲），確認報價含哪些項目、哪些另計
  3. 整理成成本比較表，附上各自回覆速度與服務窗口
  4. 選定一家後簽約
▶ 開店要注意的事
  • 貨到不驗 → 開箱才發現整批瑕疵，退貨時程把開幕週打亂
  • 前置期算錯 → 開幕週＋旺季（周年慶、百貨檔期）前沒下單，架上空給客人看
  • 進口成本別漏算：關稅、營業稅、報關費、運輸、倉儲、國內配送逐筆加總，才不會店裡賣價訂錯、毛利被吃掉
  • 標示法規：中文標籤、鞋類尺碼標示、材質／產地標示要符合台灣規定，進口報關時就要備齊
  • 驗貨：到貨要抽驗（數量、尺碼、瑕疵、鞋盒狀況），瑕疵退換貨的規則先講好，不驗貨，開箱才發現整批有問題就晚了
  • 倉儲與配送：台灣潮濕，鞋子存放要防潮防蟲；如果電商要做店到倉，物流商的服務水準先測過
  • 換季與滯銷：賣不動的鞋款要提前想好處理方式（折扣、回銷日本、轉電商），壓在倉裡就是現金卡死

數位系統

日本決定是否統一系統台灣提出在地系統需求（尤其電子發票，這是台灣法規強制項目）P1｜刷卡收單簽約到開通要數週，開幕前 1 個月就要辦好，別拖到最後▼
✔ 先做什麼
☐盤點台灣本地的銷售／庫存／會員系統選項
目的電子發票是台灣法規強制，日本系統不一定支援，要及早確認台灣選項
  1. 列出本地候選系統（重點看電子發票串接能力），一系統一行：功能／月費／串接成本
  2. 篩出 2-3 家可支援電子發票＋刷卡收單的
  3. 預約每家一次試用說明，實際操作結帳、退貨、開電子發票流程各一次
  4. 整理成比較表（功能／月費／串接成本／客服回應速度），供決策
☐列「必須跟日本同步」vs「台灣可獨立採用」清單
目的哪些系統要跟日本連線、哪些台灣自己選就行，先劃清楚才好談
  1. 逐項盤點：銷售系統／庫存／會員／電子發票／顧客關係管理，逐項標「同步日本」或「台灣獨立」的建議與理由
  2. 對「要同步日本」的項目，寫明同步什麼資料（庫存量？會員資料？）、多久同步一次
  3. 送日本確認同步範圍，回覆後照辦
▶ 開店要注意的事
  • 電子發票是法規強制 → 台灣零售一定要開電子發票（每二個月申報一次營業稅），系統不支援就不能合法營業——這是選系統的硬條件，不是加分項
  • 刷卡收單要提早申請：信用卡／行動支付收單銀行審核耗時，簽約到開通可能要數週，最晚在開幕前 1 個月辦好
  • 斷電／斷網的備援：POS（銷售結帳系統）是不是雲端？網頁不穩時能不能離線結帳？要有紙本備援流程，進店第一天就遇到伺服器掛掉的狀況要想過
  • 資料備份：會員、銷售、庫存資料每天備份，異地／雲端一份，硬碟壞了不用從零開始
  • 個資法：會員資料、LINE 好友名單的蒐集利用要遵守台灣個資法，隱私權說明寫清楚，不要被投訴
  • 系統銜接：POS、庫存、會員、電子發票如果不同廠商，串接與測試要留時間，別到開幕才發現報表打不開

品牌策略

☐規劃 IG／LINE／官網的內容架構草案
目的社群是有累積性的，先有架構再發文，不會發散

目的第一階段重點是讓台灣人理解 GROUNDS 是什麼，不是打折

☐規劃開幕活動初步構想
目的開幕活動是第一次大規模曝光，先抓時間與預算級距
  1. 定活動時間（配合開店時程），抓出與開幕日的間隔天數
  2. 定形式：媒體日／VIP 場／開幕限定企劃，各估所需人力與合作廠商
  3. 估預算級距（低／中／高三案），供日本核可

▶ 開店要注意的事

  • 開幕活動的人流與控管：媒體日／VIP 場／公開場的人數控管、排隊動線、現場補貨與收銀負荷要先排演，開幕當天爆單的備援（第二台收銀、加派人手）要先準備
  • 活動保險：非公開活動只要有人流就有責任風險，活動保險在活動前投保

CH 12

財務計畫

台灣提出草案日本核准年度預算（超過授權金額）P1｜數字範圍現在就能估，先給日本方向，不必等全案定案▼
✔ 先做什麼
☐先抓資本支出與營運支出的粗估區間
目的給日本一個可審的數字範圍，不用等第五章／第七章完全定案就能先對齊方向
  1. 資本支出：裝修＋設備連同器具的粗估區間（低／中／高三案），列出主要項目與單價來源
  2. 營運支出：租金、人事、行銷、雜費逐項列出區間，標明每月／每季
  3. 把「會影響數字的重要假設」列成腳註（例如坪數、店員人數、行銷預算佔比）
  4. 標明「待第五章定案後收斂」，送日本審年度預算用
☐訂出損益平衡點的三種假設情境
目的讓日本看到「最壞到最好」的損益邊界，方便決定投入規模
  1. 樂觀情境：高來客、高回購的參數（來客數／客單價／回購率各自給數字）
  2. 中性情境：保守一點的參數
  3. 保守情境：最低存活線，算出每月要賣幾雙才打平，並標出對應的固定成本控制重點
  4. 三案各附一行「達成條件」與「若未達成要砍的項目」
▶ 開店要注意的事
  • 現金流斷了 → 店開著但發不出下個月薪水，帳面有盈餘也救不了
  • 帳記錯 → 補稅罰款比省下的成本還多
  • 現金流比帳面盈餘重要：租金、人事、進貨是每月固定流出，第一批進貨＋裝修＋押金一次墊很大，先把「還能撐幾個月」算清楚
  • 資金分配：裝修超支是常態，預留 10-15% 備用金；行銷預算要能隨時加碼（開幕期曝光是關鍵），別把預算全部綁死在固定成本
  • 淡旺季：台灣鞋類有季節性，旺季錢進得快、淡季要看庫存水位，別用旺季的樂觀數字回頭算年度預算
  • 匯率：向日本進貨用日圓計價，匯率波動會直接改動成本，備妥兩種幣別的走勢假設
  • 稅務時點：營業稅每二個月申報、年度營所稅申報、發票與帳務要留對，帳記錯補稅罰款比省的成本還多
  • 損益要和庫存一起看：賣出去的毛利片面的盈餘不可信，庫存積壓、呆滯貨要每月攤出來看

▶ 開店要注意的事
  • 風險表寫完就放著 → 等出事才發現前兆早就出現，備援全都來不及
  • 六大風險的前兆訊號要寫成「看得出來的數字」：例如補貨風險＝安全庫存跌破水位、現金流風險＝帳上剩幾個月營運金，不要等到出事才發現
  • 風險表要有人定期看、定期更新，不是寫一次就放著；至少每月檢視一次，情況變了就重排優先序
  • 出狀況時的聯絡網先建好：誰決策、誰執行、多久內回覆，突發（倉庫淹水、社群負評爆量、店員集體離職）才不會當下慌
  • 備援先做最痛的兩個：庫存與現金流，其他風險可以邊做邊補

願景

雙方共同P2｜願景是方向不是時程，先寫方向性敘述即可，不卡任何里程碑▼
✔ 先做什麼
☐寫出願景方向性敘述
目的先有方向（為什麼在台灣做 grounds），細節等有數據再補
  1. 寫 3-5 句的願景方向（品牌精神、在台使命）
  2. 註明「待第一階段有實際數據後具體化 3/5/10 年願景」
  3. 排定下次檢討時間（例如第一年財報出爐時）
▶ 開店要注意的事
  • 願景只有口號、不連到決定 → 遇到沒答案的事大家各自解讀，方向感從開店第一週就散了
  • 願景是要拿來做決定用的，不是掛在牆上的口號：寫完後，對應到「這一年要先做到哪幾件事」要有具體對應
  • 第一年的檢討點先排好（例如：開幕後 3 個月、半年、一年各看一次），時間到了就對照實際數據回顧，不要等「有空」才看
  • 把願景翻成店員聽得懂的方向（品牌精神一句話），不然教育訓練和日常服務會跟願景脫節
