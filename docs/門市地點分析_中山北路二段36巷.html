二、人流與商圈分析

商圈定位

此址位於中山商圈（南西商圈）範圍內，以捷運中山站為核心，串聯中山北路、赤峰街、雙連一帶。

客觀數據

  • 依交通部觀光署統計，2026 年 1–3 月赤峰街商圈為台北市最強景點第 2–3 名（與心中山線形公園並列），僅次於台北101／信義商圈（1,122 萬人次）。
  • 商圈特色：由早期五金／汽車零件街，轉型為咖啡廳、甜點、古著、設計品牌與選物店聚集地。
  • 主要客群：年輕族群、文青、對設計敏感度高的消費者，以及日本／港澳觀光客。

這條巷子的實際狀況

中山北路二段36巷本身已有數家質感店家聚集，例如：

  • 瑪黑家居選物（36巷18號，黑色獨棟，蒐羅15國200+設計品牌）
  • An burger（36巷17號）

分析結論

✅ 優勢

  1. 客群高度吻合：赤峰街／中山商圈的客群（年輕、文青、重設計）正是 grounds 這種設計師鞋履品牌的核心受眾。
  2. 鄰居有加分效果：同巷已有瑪黑這類選物店，形成「有質感的巷弄」印象，逛街動線會自然帶客。
  3. 日本品牌友善區：此區日本品牌與日系風格接受度極高，土屋鞄本身能在此開店並維持 4.6 評價就是證明。
  4. 交通便利：捷運中山站（紅線＋綠線交會）步行可達，是雙線交會的高流量站。

⚠️ 風險 / 要注意的

  1. 巷弄店 ≠ 大街店：36巷是巷弄，人流性質是「目的型」而非「路過型」。

    2. → 意思是：客人多半是「特地來逛這一區」，而不是「經過剛好看到」。 → 對品牌認知度低的 grounds 來說，這代表行銷必須更用力，不能靠店面曝光自然帶客。 → 但反過來說，這區的消費者本來就有「鑽巷子找店」的習慣，這是這個商圈的特性，不算致命傷。

  2. 商圈數據 ≠ 店前人流：觀光署的數字是整個商圈，不代表這條巷子、這個店門口的實際人流。

    3. → 建議：實地做人流計數（見下方行動項目）。

  3. 土屋鞄的客群與 grounds 不完全相同：土屋鞄是成熟客群的皮革品牌（單價高、年齡層偏高），grounds 是年輕潮流鞋履。

→ 沿用同一個店面，不代表能沿用同一批客人，要留意。

📋 建議實地調查（開會前若來得及，會很加分）

  • 平日 / 假日各挑一天，在店門口記錄每小時經過人數與進店人數（各 2–3 個時段即可）
  • 觀察客群輪廓：年齡、性別、是否觀光客、有無提其他店的購物袋
  • 紀錄週邊店家的營業時間（判斷這條巷子的「活躍時段」）
  • 拍下店面外觀、招牌可視範圍、騎樓／人行道狀況

三、後續流程：公司設立 → 租約 → 裝修 → 開幕

⚠️ 順序很重要，做錯順序會出問題：

```

  1. 日本決定：子公司 / 分公司 + 法定負責人

    2. ↓

  2. 公司設立登記（經濟部）→ 取得統一編號

    3. ↓

  3. 銀行開戶 + 資本額到位（外資需經投審會核准，時程要抓長一點）

    4. ↓

  4. 以公司名義簽租約（★ 公司沒設立就不能簽約、不能開發票、不能報稅）

    5. ↓

  5. 確認建築物用途 / 使用執照是否符合零售營業

    6. ↓

  6. 室內裝修送審（如涉及）→ 施工 → 消防查驗

    7. ↓

  7. 營利事業登記

    8. ↓

  8. 招募 → 教育訓練 → 試營運 → 開幕

```

現在就能先做的（不用等日本）

  • 洽詢會計師事務所：外資設立台灣子公司的流程、時間、費用
  • 確認 grounds 商標在台灣是否已註冊（可上經濟部智慧財產局商標檢索系統自行查詢）
  • 到台北市「營業場所預先查詢系統」輸入此地址與營業項目，查詢是否符合都計建管規定

（這是台北市府提供的線上系統，可以先自己查，不用付費）

四、裝修

關鍵前提

裝修規模完全取決於「這家店是旗艦店還是市場驗證店」——這是週五必問的題目。

Brand Flagship（旗艦店）Market Validation Store（驗證店）
裝修完整品牌世界觀，客製道具，預算高沿用既有結構，輕裝修，預算控制
工期長（2–3個月以上）短（4–8週）
適合時機品牌已有認知度品牌剛進入市場、要先測水溫

以 grounds 在台灣目前品牌認知度尚低的情況，若日本沒有明確要求旗艦店規格，

「輕裝修、快開幕、把預算留給行銷」在商業上是比較合理的策略——這點可以在會議上提出討論。

要確認的事

  • 日本有沒有店舖設計規範（Store Design Guideline）？必須遵守到什麼程度？
  • 現有土屋鞄的裝潢可以沿用多少？（天花、地板、燈光、儲藏空間、試穿區）
  • 鞋類門市特殊需求：試穿椅、鏡子（低角度看鞋）、庫存區（鞋盒佔空間很大）
  • 招牌更換：外招／騎樓招牌是否需要另外申請（台北市招牌設置有規定）
  • 裝修預算誰出、上限多少

五、消防與建管（這塊最容易被低估，務必提早處理）

基本觀念

  1. 建築物「使用類組」必須符合零售營業用途。原本是店舖用途的話最省事；若原核准用途不符，需辦變更使用執照。
  2. 若涉及室內裝修（隔間、天花、防火區劃變更等），台北市需辦室內裝修審查許可。
  3. 變更使用經建管核可後，須依現行消防法令繪製消防圖說，向消防局申請審查與竣工查驗。
  4. 常見須檢討項目：滅火器、緊急照明、避難指示標示、火警自動警報設備、防焰物品（窗簾、地毯）等，實際依面積、樓層、用途判定。

好消息

土屋鞄現在就是合法營業中的零售店面，代表用途大機率已符合。 → 但仍必須調閱該建物的使用執照與原核准圖說確認，不能只靠「現在有在營業」推論。

行動項目

  • 向房東／土屋鞄索取：使用執照、原核准平面圖、消防竣工圖
  • 確認建物是否有做過合法的室內裝修審查（有沒有留下紀錄）
  • 確認建築物公共安全檢查申報是否正常（這是每年／每兩年要申報的）
  • 委託室內設計師或消防技師做一次現況評估（費用不高，但可以避免開工後才發現要補件停工）
  • 若要變更招牌／外觀，確認是否需另行申請

⚠️ 本節為方向性整理，實際法規適用（面積、樓層、類組）必須由建築師／消防技師依現場與圖說判定，

不要只憑本文件就下結論。

六、人員與排班

依現況推估的人力需求

假設營業時間比照周邊店家 11:00–21:00（10 小時／天，全年無休）：

``` 單人覆蓋需求 = 10 小時 × 7 天 = 70 工時／週 但零售現場不能長時間只有 1 人（用餐、洗手間、防竊、尖峰接待） → 尖峰時段需 2 人以上 ```

建議編制（驗證店規模）

職位人數說明
店長1正職，負責營運、進退貨、報表、排班
正職店員1–2撐起平日基本班
兼職店員2–3補假日尖峰、輪休替補

若定位為旗艦店、坪數大、來客多，人力要往上加。

排班要注意的台灣法規重點

  • 一例一休：每 7 日中應有 1 日例假、1 日休息日
  • 每日正常工時 8 小時、每週不得超過 40 小時，超過為加班（加班費率有規定）
  • 排班表、出勤紀錄必須留存（勞檢會查）
  • 國定假日出勤需加倍工資 → 開幕檔期若遇連假要先算進預算
  • 勞健保、勞退 6% 為雇主法定成本，編人事預算時不能只算薪水

待確認

  • 人事預算（總額）多少？
  • 薪資結構：底薪 + 獎金？獎金走團績還是個績？（詳見會議提問清單）
  • 店長由台灣招募還是日本指派？
  • 開幕前需要多久的教育訓練期？（訓練期也要付薪水，要算進預算）

七、目前最大的未知數（優先釐清）

未知數為什麼重要
★ 這家店的定位（旗艦 / 驗證）決定裝修預算、人力、進貨量、行銷規模 —— 幾乎所有數字的前提
★ 店面的實際交接方式土屋鞄退場？共用？租約轉讓？決定法律與財務結構
