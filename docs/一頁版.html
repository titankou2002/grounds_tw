grounds Taiwan｜一頁版（給決策者）

一句話：把日本品牌 GROUNDS 的鞋子帶進台灣的第一間直營店。這份只講三件事——花多少錢、多久開、卡在哪，還有「要拍板什麼」。網頁版：docs/一頁版.html。

1. 這是什麼

  • 品牌：GROUNDS（株式會社 FOOLS，日本）——以「教育式試穿」與泡泡厚底鞋聞名的設計師品牌
  • 型態：台北第一家直營實體店＋品牌型官網
  • 進貨：初期從日本倉小量多批進口（交期海運 2~4 天），不一次押大量

2. 花多少錢？（三段式：金額狀態只分三種）

① 已確定（有報價，可直接編預算）

項目金額
台灣商標官費（品牌核心 3 件 × 第25+35 類）NT$15,600（＋事務所代理費，報價中）
會計師／律師（子公司設立＋每年記帳）已向 2~3 家詢價，報價彙整中
物流／報關（海運、空運、倉儲）已向 2~3 家詢價，報價彙整中

② 等日本拍板（決定了才會有數字）

  • 公司資本額 → 日本決定
  • 店面坪數／租金／裝修 → 依第一家店定位（日本決定）
  • 首批進貨金額 → 依引進範圍與出貨模式（日本決定）

③ 資料還沒有（本週就能開始補）

  • 人力：店長／正職／兼職人數與薪資
  • 行銷：開幕週與第一季預算

3. 多久開幕？（里程碑＋依賴條件，不填假日期）

里程碑依賴條件狀態
商標送件（品牌核心 3 件）日本同意申請人名義送件即取得優先日；審查 6~12 個月不影響開店
公司成立（100% 日本持股子公司）日本拍板子公司＋資本額行政流程約 2~3 個月
第一家店選址→簽約→裝修→消防定位與租金預算拍板消防沒過不能營業
首批進貨到店引進範圍與出貨模式拍板自日本倉海運 2~4 天
系統＋招募＋訓練刷卡收單開通簽約到開通約數週，開幕前 1 個月辦好
開幕上面全數完成沒有固定日期，各里程碑依序走完就開

4. 現在卡在哪？（不是等日本，是讓日本能拍板）

  • 台灣端本週就能推進：詢價會計師／律師、物流報關、商標事務所；完成市場分析與風險章節
  • 等日本拍板（拍板一項，對應金額與時間就從「②」移到「①」）：公司結構與資本額、第一家店定位、出貨模式、商標申請人名義
  • 一句話：台灣側準備已就緒，關鍵是日本這幾項決定。

5. 要拍板什麼（決策清單）

  • 子公司或分公司？（建議子公司）
  • 資本額多少？
  • 第一家店定位：旗艦店 or 驗證店？
  • 出貨模式：日本倉出貨 ok？
  • 商標申請人名義（建議：日本母公司先送件，公司成立後移轉子公司）
  • 系列名（JEWELRY／MOOPIE 等七個）是否全辦？
