grounds 的建議：用子公司

grounds 的情境：100% 日本持股、要開實體門市、未來可能展店、需要簽租約/開銀行帳戶/僱員工、需要持有台灣商標。

建議用子公司，理由：

  1. 獨立法人 → 租約、銀行帳戶、商標都掛在子公司名下，日本母公司風險隔離
  2. 展店彈性 → 第二家店可直接增資或轉投資
  3. 商標歸屬 → 子公司持有台灣商標，未來要賣台灣業務或引入股東都方便
  4. 稅務 → 雖然匯回盈餘要扣 21%，但台灣營所稅僅 20%，實際差異不大
  5. 獨立決策 → 台灣端日常營運不需每次回日本批准

需在會議中確認的子項目：

  • 子公司還是分公司？日本是否認同子公司方案？
  • 法定負責人由誰擔任？
  • 資本額多少？資金何時到位？
  • 若採子公司，台灣商標登記在誰名下（見商標章節）
