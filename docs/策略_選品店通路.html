四種處理模式比較

模式A：全部收回（獨家直營）

開店後終止所有選品店供貨，只在自己的直營店與官網販售。

優點缺點
價格完全控制失去現有通路曝光量
消費者資料全在自己手上選品店客人可能不知道開了新店
利潤全拿短期營收可能下降
品牌形象統一管理跟選品店關係破裂，口碑受影響

模式B：並行但統一價格

直營店開了之後選品店繼續賣，但統一建議售價。

優點缺點
通路覆蓋率最大價格難真正統一（選品店可能偷打折）
選品店客人=免費品牌曝光直營店與選品店互相搶客人
保留合作關係難以控制陳列與服務品質

模式C：階段性退場（漸進式）

開店後 6~12 個月內逐步減少選品店供貨，等直營店站穩後完全收回。

優點缺點
平穩過渡，不影響營收需精準控制退場時間表
給選品店緩衝期，保持關係管理複雜度高
直營店有時間建立客源可能拖太久導致進退兩難

模式D：選品店升級為經銷夥伴

不收回，改成「正式經銷商」模式，簽訂經銷合約（最低售價、陳列標準、退換貨規則）。

優點缺點
通路覆蓋最大控制力比直營弱
選品店有動力推廣經銷商管理需人力
減少平行輸入/水貨風險價格體系複雜

建議策略：模式C（階段性退場）

考量 grounds 是新品牌在台灣：

  1. 第一年 → 選品店是重要品牌曝光來源（消費者不知道 grounds 是什麼，選品店能教育市場）
  2. 開店後 → 直營店建立品牌體驗，選品店繼續維持通路覆蓋
  3. 6~12 個月後 → 若直營店業績穩定，開始減少選品店供貨
  4. 第二年 → 評估完全收回，或保留 1~2 家最重要的選品店作為「經銷夥伴」
